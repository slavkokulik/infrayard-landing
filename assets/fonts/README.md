# Inter webfonts

Original, unmodified **Inter 4.1** variable webfonts by Rasmus Andersson and the Inter Project Authors, self-hosted under the included SIL Open Font License 1.1.

- Typeface: https://rsms.me/inter/
- Normal source: https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1
- Italic source: https://rsms.me/inter/font-files/InterVariable-Italic.woff2?v=4.1
- Licence source: https://github.com/rsms/inter/blob/master/LICENSE.txt
- Retrieved: 2026-10-17.

The normal font is preloaded. Both fonts use `font-display: swap`; italic loads only when needed. No visitor request is made to a third-party font provider. Keep `Inter-LICENSE.txt` with the font files when redistributing the website.
